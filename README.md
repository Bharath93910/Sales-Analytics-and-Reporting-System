# Sales-Analytics-and-Reporting-System
Python and SQL sales analytics system: cleans 5,000+ records, generates monthly/yearly reports, and builds a dashboard with Pandas and Matplotlib. Sales analytics and reporting system using SQLite, SQL (joins, window functions) and Pandas/Matplotlib to clean data, report sales trends and find top products and customer insights.

A Python and SQL project that cleans 5,000+ sales records, produces monthly and yearly
reports, and builds a sales dashboard with Pandas and Matplotlib.

![Dashboard](charts/dashboard.png)

## What it does
- Loads raw sales data into SQLite and cleans it with SQL (removes duplicate orders,
  rows with missing customers, invalid quantities and unknown products)
- Generates monthly and yearly reports with growth rates, using GROUP BY and window functions (LAG)
- Finds top-selling products, best categories and regions, and loyal vs occasional customers
- Draws charts and a one-page dashboard automatically

## Tech stack
Python, SQLite, SQL (joins, aggregations, CTEs, window functions), Pandas, Matplotlib

## How to run
```
pip install -r requirements.txt
python generate_data.py
python load_db.py
python charts.py
```
Reports are saved in `reports/` and charts in `charts/`.

## Project structure
- `generate_data.py` creates the sample dataset
- `schema.sql` defines the tables
- `queries.sql` holds all SQL queries
- `load_db.py` loads data, runs the cleaning and reports
- `charts.py` builds the charts and dashboard

## Results (sample data)
- 5,330 raw rows were cleaned to 5,085 valid orders (245 bad rows removed)
- Revenue grew 14.9% from 2024 to 2025, with a peak in November
- A small group of loyal customers (50 of 384) brings in about half of the revenue

## Note
The dataset is synthetic, generated by `generate_data.py`, so the business findings are examples.
